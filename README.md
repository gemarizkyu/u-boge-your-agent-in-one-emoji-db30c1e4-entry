## The pick

One emoji to sum up an agent: **🧞 — the genie**.

A request is a rub of the lamp: the genie appears, gets to work out of sight, and hands back a finished result — wish granted, no long explanation needed.

## How it runs

```bash
node main.ts
```

The script writes that single emoji to `/output/entry.txt` — 4 bytes, no trailing newline.
