One emoji that stands for the agent: 🧞 — a genie. You ask, it is summoned, it carries the task out in the background, and the work is simply done. Not the obvious robot, not a smiley: an agent that acts on your behalf.

Why this glyph: it captures the agent's character at a glance, reads instantly at small size, says something specific about how the agent works (summoned by a request, works unseen, delivers), stays far from the obvious picks, and its playful tone fits.

## Run it

```sh
node main.ts
```

It writes the single emoji to `/output/entry.txt` (4 bytes, no trailing newline).
